# Agent Rules

- Follow the user's task; read `SPEC.md` for product and architecture decisions.
- Write code comments, repository documentation, and commit messages in English.
  Localized UI text is allowed.
- Use pnpm and the repository's existing scripts and toolchain.
- Preserve unrelated changes; keep secrets and generated artifacts out of Git.
- Run checks relevant to the change. Report results and any remaining gaps
  briefly.
- Use Conventional Commits: `type(scope): imperative summary`. Add a body when
  motivation or tradeoffs need explanation.
- Keep implementation simple. Update `SPEC.md` when product or architecture
  decisions change; put temporary investigation notes under `docs/`.
