# Icon Generation Attribution

The project icon assets in this directory were generated for Markdown
Publication Studio with the OpenAI GPT-5.6 Sol-assisted image-generation
workflow.

- `icon-dark.png`: a restrained dark variant with a near-black background and a
  soft ivory M mark.
- `icon-light.png`: a light variant with a pale stone background and a graphite
  M mark.

The generation brief requested a modern capital-M monogram while preserving a
centered geometric folded-ribbon structure. The assets were generated on
2026-08-22 and are retained as project design assets.

Model reference:
[GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol).
